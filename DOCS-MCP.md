# Documentación del Proyecto project-docs-mcp

## Título del proyecto
project-docs-mcp

## Descripción detallada
MCP (Model Context Protocol) diseñado para que modelos de IA como Claude generen documentación completa y técnica de proyectos de software. No es una herramienta externa sino un protocolo estructurado que guía al modelo a través de pasos sistemáticos.

## Arquitectura
Arquitectura simple basada en Node.js con un enfoque declarativo que define pasos específicos, criterios para ignorar archivos y un formato de salida estructurado.
